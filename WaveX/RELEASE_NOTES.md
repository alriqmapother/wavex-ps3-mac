**Wave X** — the PlayStation 3 XMB wave as a native macOS live wallpaper, with lock-screen support.

## Install
1. Download the `.dmg`, open it and drag **Wave X** into **Applications**.
2. The app is not notarized: right-click **Wave X** → **Open** → **Open** the first time (or System Settings → Privacy & Security → **Open Anyway**).
3. Click the wave icon in the menu bar. **Variants…** picks a colour, **Settings…** tunes the wave and sparkles.
4. Lock screen: open System Settings → Wallpaper once and scroll to the aerials, then in Wave X choose **Lock Screen… → Export & Install**. Pick the **Wave X** tile in the Landscape row.

## What's inside
- Live Metal wallpaper on every display and Space, behind Finder's icons, 60 fps, 4× MSAA; pauses when locked, asleep or covered.
- 38 colour variants: 12 PS3 month palettes × Day / Night / Enhanced, plus Black and Custom RGB, with hover-to-preview and crossfades.
- HEVC lock-screen export with temporal sub-layers (`tscl`/`tsas`), registered in the macOS aerial wallpaper catalog.
- Universal binary (Apple Silicon + Intel), macOS 14 or newer. Lock-screen integration verified on macOS 27 / Apple Silicon.

Built from the reverse-engineered WebGL implementation by [linkev](https://github.com/linkev/PlayStation-3-XMB) (MIT).
